# TMS FNC Cloud Pack - Exemplos

Demos, vídeos e informações para utilização do TMS FNC Cloud Pack.

O TMS FNC Cloud Pack é um conjunto de componentes para Delphi e C++Builder que facilita a integração de aplicações VCL, FireMonkey e TMS WEB Core com serviços em nuvem. Ele oferece conectores prontos para armazenamento, e-mail, calendários, pagamentos, tradução, inteligência artificial e APIs REST.

Entre os componentes estão: 
- **TTMSFNCCloudStorageServices**, que permite alternar entre Google Drive, OneDrive, Dropbox e Box
- **TTMSFNCCloudAI**, para acessar serviços de IA;
- **TTMSFNCCloudTranslation**, para traduzir textos;
- **TTMSFNCRESTClient**, para integrar APIs próprias.
